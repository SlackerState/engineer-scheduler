至

回看任意时间段每位工程师的排班和工单。上门按 实际到达 → 出发 → 计划上门 算日期（和排班表一致）；现场工时 = 到达 → 现场完工，单次超过 小时的多半是完工没及时提交，不计入工时、单独计数；响应 = 派工 → 到达；超期 = 到达晚于预约上门（考核截止）。排班只算工作日、按整天算：当天有派单算外出，否则看排班表；周末的上门工单照样计入工单数和工时。点一行看这位工程师的排班日历和工单明细。

人员

「D365 别名」填 D365 里显示的工程师全名（如 Lee Ryan、Winzar Charles），多个用逗号分隔；不填时按姓名中任一单词自动匹配。类型决定排班表底部统计口径：外勤算「外勤可派」，驻点算「驻点在岗」。

设置

D365 登录

点「登录 D365」会弹出浏览器窗口，用公司账号登录（含 MFA）。登录成功后窗口会自动关闭并开始同步，之后软件在后台复用这个登录状态。平时直接点「同步 D365」也行：没登录时会自动弹出登录窗口。
